## 📈 Market Trends

### 1. The “virtual company” product wave ships — buyers want labor, not tools

- **Tycoon AI / Astra (the AI CEO).** You get an “AI chief executive” that manages Claude Code and Hermes, plus a dozen plug-and-play roles (CMO, CTO, and more). Set a KPI like “10x traffic this month” and it breaks the plan, delegates tasks, tracks progress, and asks for approval when needed. This is the most literal productization of “one-person company + AI employees.”
- **MGX / MetaGPT (1,350 upvotes, PH weekly #1).** A multi-agent dev team that simulates PM / architect / engineer collaboration, turning one sentence into runnable code and docs. Agentplace sells “text instruction → interactive AI website.”
- **Architect by Lyzr.** Described as “n8n meets Lovable” — the pitch isn’t smarter, it’s that every decision, integration, and flow is *visible and controllable*. Clear signal: buyers want digital labor that ships results, not another chat window.

### 2. The moat moves from model to skills / harness

- **GitHub Trending on 7/19 is a skills parade.** anthropics/knowledge-work-plugins (15,564★), multica-ai/andrej-karpathy-skills (155,118★), Anthropic-Cybersecurity-Skills. CLAUDE.md / Skills are essentially “loadable capability packs” — a domain’s rules, examples, and checklists frozen into Markdown, injected into the agent on startup.
- **The skills format is now an open standard.** Pioneered by Anthropic, the SKILL.md structure is supported by Claude Code, Cursor, and more. Models are converging; what diverges is *the domain SOP and verified process you hang on top.*
- **“Harness Engineering” is named the key 2026 paradigm.** The community is systematizing context architecture, self-validation loops, context isolation, and entropy governance — i.e. how to actually raise an agent to do real work. Writing skills and designing harnesses is replacing “writing prompts” as the core skill.

### 3. Code knowledge graphs go local + agent routing gateways consolidate

- **Understand-Anything (31,452★) / codegraph (25,285★).** The former turns any codebase into an interactive knowledge graph agents can explore and query; the latter pre-indexes locally to directly cut a coding agent’s token spend and tool calls. Context “entropy governance” finally has off-the-shelf tooling.
- **OmniRoute-class unified gateways.** One endpoint connects Claude Code / Codex / Cursor front-ends to multiple model vendors, with native model fallback, token compression, and MCP. The pain of juggling multiple model CLIs and API keys is getting an engineering fix.

## 💡 Build Directions (the actionable part)

Each direction is spelled out as **what to build + which AI tool stack + rough cost / timeline** so you can copy it straight into a spec. These are distinct from the previous issue.

**1. Vertical “AI role team” wrapper for a specific solo business**

- *What:* Don’t rebuild Tycoon (it already did the generic framework). Build a role team for *one narrow business* — e.g. “an AI ops squad for independent newsletter writers (topic + draft + distribute + reply)” or “an AI property manager for Airbnb hosts (pricing + copy + support).” Use generic orchestration as the substrate; you own the industry SOP and role definitions.
- *Stack:* Tycoon-style orchestration (or self-hosted n8n + multi-agent) + Claude Code / Hermes (execution) + your industry skills (the actual moat).
- *Cost / timeline:* 1 person, 2–4 weeks to MVP; ~$20–200/mo (subscriptions + API), near-zero upfront.

**2. Sell a “skills pack / CLAUDE.md template library” digital product**

- *What:* Freeze the repetitive work of a founder niche into loadable skill packs — e.g. “10 must-have skills for solo SaaS founders (launch checklist / refund handling / SEO)” or “skills for indie game devs (balance tuning / Steam copy).” Pure digital product, zero marginal cost.
- *Stack:* Anthropic Skills format (SKILL.md + resources) + Gumroad / LemonSqueezy for checkout + your GitHub as the showcase and update channel.
- *Cost / timeline:* single skill in 1–3 days; template library drives marginal cost to ~zero — the textbook one-person digital product, subscription or buy-once.

**3. Local code knowledge graph as a service (privacy lane)**

- *What:* Using the Understand-Anything / codegraph idea, give small teams that refuse to push code to the cloud a local code graph + agent Q&A. Sell “code never leaves the domain, but the agent still understands your repo.”
- *Stack:* open-source code-graph project (self-hosted) + local small model (gguf) for Q&A + light frontend (desktop / intranet app).
- *Cost / timeline:* 1 person, 4–8 weeks; edge box is a one-time buy, no monthly API fee, high margin — fits保密-sensitive agencies and contractors.

**4. Solo-developer model routing gateway micro-SaaS**

- *What:* OmniRoute validated the pain — solo devs are crushed by multiple model CLIs, API keys, and fallbacks. Ship a lightweight gateway for solo devs: one endpoint to many models, auto-fallback, per-key rate limits, and a cost dashboard.
- *Stack:* open-source gateway framework (OmniRoute-class) + per-key rate-limit / billing module + a simple cost dashboard.
- *Cost / timeline:* 1 person, 3–6 weeks; usage-based, $50–200/mo to validate, with a side product of “how many tokens you saved” data.

## ⚠️ Risk Factors

- **Role-team wrappers commoditize fast.** Tycoon and MGX flatten the barrier for “generic AI teams.” The vertical wrapper you ship today can be officially supported by the substrate tomorrow — your moat has to be industry SOP and distribution, not orchestration tech.
- **Multi-role collaboration is 10x harder than a single agent.** How roles hand off context, who can touch production, how to roll back on failure — all new potholes. Budget 2–3x the integration time you first estimate.
- **Compliance and data ownership.** The moment AI employees touch real customer data (email, CRM, conversations), GDPR and industry retention rules switch on. Local stacks dodge part of it, but your terms and disclosures can’t be skipped.
- **Runaway compute cost.** Multiple models + multiple keys + parallel roles, without per-key limits, means a stuck loop burns the bill. Write the cost guardrails before launch, not after.

## 🚀 Action Recommendations

**For starters (no first paid deal yet):**

- ✅ Pick **one business you already understand**, and use Tycoon-style orchestration + Claude Code to staff a “small AI squad that does the work” within two weeks. Don’t agonize over building your own framework first.
- ✅ Write your industry process as skill packs — that’s the asset nobody can copy, far more important than model tuning.
- ✅ Install the cost guardrail on day one: a per-key rate-limited routing gateway so multi-agent loops can’t bankrupt you.

**For mature teams (shipping, adding AI employees):**

- ✅ Use official skills (anthropics/knowledge-work-plugins-class) to plug agents into existing flows — ~70% less work than building integrations yourself.
- ✅ Put sensitive code / customer data on local knowledge graphs + local small models, and sell “data never leaves the domain” as a feature.
- ✅ Give every AI role its own key and budget cap — bold enough to delegate, safe enough that one runaway role can’t take down the whole line.
