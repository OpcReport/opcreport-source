# Agents Are Writing Production Code at Scale — and the Solo Playbook Just Changed

> Hourly intelligence briefing for solo founders and indie hackers building with AI. This edition was compiled from Hacker News, GitHub, Product Hunt digests, and primary engineering blogs on July 22, 2026.

## TL;DR

The story this week is not “AI can code.” It’s that **agentic coding is now trusted with production-scale, messy real-world work** — Anthropic published how it runs large code migrations with Claude Code, and the tooling layer around agents (MCP, orchestration, observability, even agent bank accounts) is hardening fast. For a solo founder, that means the bottleneck is no longer “can I build it” but “which narrow wedge do I own.” This report tells you where to point and which stack to use.

## Key Insights

**Where should you build?** Stop shipping generic chat wrappers. The signal is unambiguous: differentiation now lives in (1) vertically-specific agents with a real workflow wedge, (2) the plumbing that makes agents trustworthy and cheap to run, and (3) compact open/local models for cost- and privacy-sensitive use cases.

**Which AI tool should you use?** For almost every solo build in 2026 the pragmatic stack is: **Claude Code or Cursor** to author the product, **Supabase** for the backend, **Dify or n8n** to orchestrate agents, and **MCP servers** to plug in real tools. Reach for **Ollama** when you need local/private inference, and **ElevenLabs / Cartesia** for voice.

## Build Directions (the actionable part)

These are the directions worth your time this quarter, each with a concrete stack.

**1. A vertical agent for one painful workflow**  
Pick a job people hate doing by hand — contract review, job-description-to-shortlist, SEO/technical audits, invoice reconciliation. The wedge is the *workflow*, not the model.

- Stack: **Claude Code** to scaffold + **Dify** (or **n8n**) to orchestrate the steps + **Supabase** to store state + one domain data source (API or scraped corpus) + **Exa/Perplexity** for retrieval.
- Cost/cycle: ~$50–150/mo, 1–2 week MVP. Monetize per-use or flat SaaS.

**2. Agent trust & cost plumbing**  
Everyone is deploying agents; almost nobody has guardrails or unit economics. Build the layer others bolt on:

- A **token/context budget dashboard** (clone the “monitor Claude Code consumption” idea) for any agent runtime.
- An **MCP server** that compresses or caches context for a specific tool (the 98%-reduction pattern).
- Stack: **Python + FastAPI**, ship as an MCP server or a hosted dashboard; **Supabase** for accounts.
- Cost/cycle: near-zero infra if self-hosted; 1 week to a usable v0.

**3. A compact, domain-specific open model as a product**  
Follow the Cisco Antares template: take a narrow domain (legal clauses, medical triage, security logs), fine-tune or distill a small model, and sell it as a cheap API.

- Stack: **Ollama / llama.cpp** for serving + a small curated dataset + **FastAPI** wrapper + **Vercel** frontend.
- Cost/cycle: free to run locally; ~2–3 weeks to a credible demo; margin comes from hosting convenience.

**4. Local/private agent for SMBs**  
Privacy-sensitive small businesses (clinics, law offices, agencies) want agents but can’t send data to a frontier API. Sell a local, self-hosted agent swarm.

- Stack: **Ollama** + a lightweight orchestrator (AutoGen/crew-style) + **MCP** for their tools + a simple **n8n** control panel.
- Cost/cycle: one-time setup + monthly retainer; differentiation is trust + on-prem, not features.

## Risk Factors

- **Saturation is real.** GitHub returned **42,767 new repos** matching “AI agent” in July 2026 alone. A generic wrapper will not be found. Own a wedge or don’t ship.
- **Cost creep is silent.** Agentic token use can run 2–5× a base subscription. Without budgets and observability, your unit economics invert the moment usage scales.
- **Platform dependency.** Building on someone else’s agent runtime or model API means their pricing, rate limits, or deprecations become your outage. Keep a swap path (open-model fallback).
- **Demo ≠ product.** Agents look magical on the happy path and fall apart on edge cases. Trust, safety, and eval are the moat — not the screenshotted demo.
- **Compliance lands late.** Voice agents and anything touching customer data trigger telephony rules, GDPR/CCPA, and AI-disclosure requirements. Bake it in early.
