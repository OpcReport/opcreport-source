# Coding Agents Cross 80M Users and the Skills Gold Rush Begins

**Where solo builders should place their bets — July 26, 2026**

---

## Key Insights

The single most important shift right now: **coding agents have stopped being tools and become distribution platforms.** OpenAI’s Codex went from roughly 1 million users in February to 8 million by July 14 — a 7x run in five months — and it shipped updates two days straight on July 23-24 to keep pace with Anthropic and Cursor. Meanwhile, Anthropic’s Agent Skills ecosystem just caught fire on GitHub.

For a solo builder, the takeaway is blunt: the money is no longer in building “another Cursor.” It’s in building **on top of** these agents — packaging vertical skills, shipping narrow SaaS, and serving the private/local deployments the big platforms won’t touch. Whoever wraps a real industry workflow into something an agent can call directly captures this wave.

**Numbers that actually change your decision:**

- **8M** — Codex users (up from ~1M in February; 7x in five months)
- **$0.10/hour** — Grok STT 1.0 batch transcription on OpenRouter, undercutting Deepgram
- **80.8%** — Claude Code’s SWE-bench score; its codebase is now largely AI-written, output up ~250%
- **14B, on-device** — Microsoft’s Aion 1.0 agent model shipping in-box on Windows 11, no cloud required

## Market Trends

### 1. Coding agents are the new “app store” — and the user land-grab is on

Codex’s curve tells the story: ~1M users in February, 8M by July 14. That kind of growth pulls an entire developer mindshare battle with it — Codex lead Tibo Sottiaux teased “tomorrow is feeling codexy” on July 23, and OpenAI dropped a fresh batch of updates the next day. On the other side, Claude Code leads on raw coding ability (80.8% SWE-bench), with Anthropic disclosing that its codebase is now essentially self-written and output has jumped ~250%.

- **What it really means:** These agents are becoming *distribution entry points* — the way the App Store once was. You don’t need to build the model; you build the thing that runs on it.
- **What to do:** Stop agonizing over which tool is “best.” Pick one (Claude Code, Codex, or Cursor), treat it as your full-time engineering team, and pour your energy into product and distribution instead.

### 2. The Agent Skills gold rush — “packaging skills for agents” is a category now

On July 25, Jesse Vincent’s (obra) open-source project **Superpowers** added ~500 GitHub stars in a single day — and it didn’t happen alone. `mattpocock/skills` and `awesome-claude-skills` rode up Trending right beside it. Superpowers isn’t an app or a model; it’s a framework that breaks an agent’s abilities into **reusable, composable skill modules** (TDD, systematic debugging, brainstorming, even “writing new skills”) and forces the agent through a real engineering process instead of sprinting straight to code.

- **What it really means:** With Anthropic’s Agent Skills ecosystem ablaze, “skill packs” are becoming a standalone product category — echoing the early days of browser extensions and VS Code plugins.
- **What to do:** This is one of the lowest-barrier, closest-to-revenue entry points available today. Wrap a workflow you know cold (contract clause review, financial reconciliation, SEO audits) into a Skill, and you have a shippable, chargeable product.

### 3. Local / private deployment is becoming a real moat

Two parallel signals. At Build 2026, Microsoft baked its 14B **Aion 1.0** agent model straight into Windows 11 (with a Windows Agent Framework), leading with “no cloud required.” In the indie community, the “local LLM vs. cloud API” architecture debate — cost, latency, data sovereignty — is now a front-burner topic. At the same time, xAI’s Grok STT 1.0 landed on OpenRouter at **$0.10/hour** for batch transcription, blowing past Deepgram’s pricing.

- **What it really means:** Base capabilities (transcription, inference) are collapsing in price, while “data stays on-prem” compliance demand is rising. Those two forces open a gap tailor-made for solo builders.
- **What to do:** For law firms, clinics, and finance teams that **can’t send data to the cloud**, building local/private agents is a narrow market the giants can’t be bothered with — and you can own it.

## Build Directions

Four concrete directions you can start this week, each with a specific stack.

| Direction | Build | Stack | Cost / Timeline |
| --- | --- | --- | --- |
| **Narrow vertical SaaS** | A small-but-complete SaaS for a niche you understand (freelancer quotes, vet appointments, e-com returns) | Claude Code/Codex for build + Supabase (backend/auth) + Vercel (deploy) + Stripe (payments) | ~$50/mo to start; MVP in 1-2 weeks |
| **Agent Skill packs** | Wrap a pro workflow into a Claude Code-callable Skill (contract review, financial cross-checks, competitor monitoring, SEO audits); open-source to acquire, paid for premium | Markdown + scripts patterned on Superpowers / awesome-claude-skills; GitHub for distribution; Gumroad/Lemon Squeezy for payments | Near-zero infra; 3-7 days per skill |
| **Local / private agents** | On-prem document/QA agents for firms that can’t use the cloud; you sell “data never leaves the building” | Open-weight model (Llama/Qwen) + Ollama for inference + Microsoft Aion / Windows Agent Framework for desktop; local vector store for RAG | Hardware once + delivery; $2k-10k/client, high margin |
| **Voice / transcription micro-products** | Meeting notes, podcast-to-text + summary, voice notes — margins opened up by cheap transcription | Grok STT (OpenRouter) for transcription + Claude/GPT for summaries + light frontend | Marginal cost near zero; chargeable in 2-3 weeks |

The through-line: don’t compete on the base model or the raw capability. Compete on the **workflow and the specific customer** wrapped around it.

## Risk Factors

- **The “wrapper” gets commoditized fastest.** Anyone can ship a SaaS on a coding agent in a week. Without domain depth or proprietary data, you’ll be cloned to zero margin within three months.
- **Platform dependency cuts both ways.** A thriving skill/plugin ecosystem also means the platform can change the rules overnight — one Anthropic API or Skills-format change can force a rewrite. Don’t bet the whole company on a single ecosystem.
- **Collapsing base prices are a double-edged sword.** $0.10/hour transcription lets you in — and lets your competitors in. “Cheap” is not a moat; you need workflow and context on top.
- **Local delivery is heavy and hard to scale.** Private deployments command high prices but require implementation and maintenance. Do too many and you become an agency, not a product company. Know that before you sign.

## Action Recommendations

**If you’re just starting out:**

- ✅ Master exactly one coding agent (Claude Code or Codex). Stop spending time on tool comparisons.
- ✅ Enter via a Skill pack or a narrow SaaS — ship a chargeable MVP in 1-2 weeks at minimum cost.
- ✅ Pick an industry you genuinely understand; domain knowledge is the gap AI can’t close for your competitors.
- ✅ Post early on Indie Hackers / Product Hunt / Hacker News to gather feedback before doubling down.

**If you already run a product:**

- ✅ Evaluate packaging your core workflow as an Agent Skill to open a new acquisition channel via Anthropic’s ecosystem.
- ✅ Add a “local / private deployment” tier as a high-price SKU for compliance-sensitive customers.
- ✅ Wire in already-collapsed base capabilities (voice/transcription) to cut cost and lift margin.
- ✅ Adopt a multi-model strategy (plan with Opus, execute with a cheaper model) so a single vendor can’t lock in your costs.
