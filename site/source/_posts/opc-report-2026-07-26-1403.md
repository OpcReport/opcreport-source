For two straight quarters the story has been the same: coding got abstracted away. Claude Code now writes itself, Opus-class API pricing collapsed to a third of last generation, and one person running 3–5 products is no longer heroic — it’s normal. But when “can you build it?” stops being a differentiator, the entire market pressure shifts somewhere else. This quarter it shifted to distribution — and specifically, to whether an AI answer engine will name your product when a buyer asks.

## Key Insights

**The one judgment that matters this week:** the bottleneck for solo builders has fully migrated from *building* to *being found*. More purchase decisions now start inside ChatGPT, Perplexity, and Gemini than inside a Google results page — and those engines name only one to three products per answer. The most actionable move right now is to treat **being cited by AI answer engines (AEO/GEO)** as a first-class growth channel, not an afterthought. Default stack: Claude Code + structured content + an AEO/GEO visibility layer.

- **Opus-class API is now $5/$25 per million tokens (in/out)** — roughly 67% cheaper than the prior generation. The marginal cost of building fell to near-zero, so competition floods to distribution.
- **Heavy indie API bills commonly run $100–300/month;** switching your default to Sonnet 5 recovers 20–40 points of gross margin.
- **AEO/GEO visibility tools now start at ~$50/month** (AthenaHQ, Profound, HubSpot AEO) — answer-engine optimization has moved from concept to standard marketing stack.
- **Micro-product exits are liquid:** Indiemaker-class platforms standardize $1K–$500K sales at 30–40x monthly revenue, giving agent-built products a repeatable cash-out.

## Market Trends

### 1. The build side is solved; competition now piles onto distribution

The signals of the last six months point the same direction. Anthropic disclosed Claude Code is 100% self-written and its engineers “only write prompts now.” Opus-class pricing halved and halved again. The net effect: a laptop plus a few configured agents outproduces what used to take a five-person team.

Once the build barrier collapses, “I can make it” stops being anyone’s edge. When everyone can ship a working SaaS in a week, the market instantly re-sorts around who gets *seen*. That’s the whole thesis this issue: **building is the solved problem; distribution is the unsolved one.**

- Thin wrappers are on borrowed time — each model release eats another layer of pure-wrapper products.
- The only remaining moats are proprietary data, private integrations, and the ability to actually reach your target buyer.

### 2. The buying entry point is moving from the search box to the chat box

People increasingly don’t Google “best invoicing tool.” They ask ChatGPT or Perplexity to “recommend an invoicing tool that auto-reconciles.” The AI returns one answer, usually naming just one to three products. Being *in* that answer — versus being invisible — is the new life-or-death line.

That’s created a fast-forming category: **AEO / GEO (Answer Engine Optimization / Generative Engine Optimization)** — getting your brand cited and recommended inside LLM-generated answers.

- A tool layer already exists: AthenaHQ, Profound, and HubSpot AEO ($50/mo) score your “AI visibility,” tracking how often and how positively your brand shows up across ChatGPT/Gemini/Perplexity.
- The methodology is standardizing too: entity mapping (tying your brand to authoritative entities like LinkedIn, Crunchbase, Wikipedia), structured content, and strategic Reddit/Quora mentions that feed LLM retrieval and training.
- Open source is following: frameworks like aeo-box are appearing on GitHub, a sign that indie builders are already replicating the playbook.

### 3. Distribution and exit layers matured together into a full loop

Getting cited isn’t enough on its own. Solo builders need a complete build → distribute → monetize/exit loop — and every link is filling in:

- **Skill distribution:** subagents.cc, codegen.com, and opc.dev turn “package a vertical skill → acquire users for free” into reality. Lowest-CAC entry in the ecosystem.
- **AI-visibility distribution:** AEO/GEO tools make “cited by answer engines” measurable and optimizable.
- **Exit liquidity:** Indiemaker (1kprojects.com) standardizes $1K–$500K micro-product sales at 30–40x monthly revenue, making “build-then-sell” a sustainable strategy.

## Build Directions

### Direction 1: AEO/GEO visibility service for small brands (strongest signal this week)

- **What to build:** Monitor and lift the probability that a solo dev, small SaaS, or local service gets recommended inside AI answers. Deliverable = visibility report + structured-content rework + authoritative-entity linking. Enterprise has AthenaHQ/Profound; the indie/small-team tier is nearly empty.
- **Stack:** Claude Code + Sonnet 5 to crawl and analyze brand mentions across LLMs; Claude to generate Schema/structured data; Next.js + Supabase frontend; Stripe/Paddle payments. Under $100/mo to start, 2–3 week MVP. Pick one vertical (law firms, dentists, SaaS-going-global) and nail it first.

| Layer | Tool | Cost |
| --- | --- | --- |
| Analysis agent | Claude Code + Sonnet 5 | ~$20–100/mo usage |
| Visibility benchmark | AthenaHQ / Profound / HubSpot AEO | from $50/mo |
| App infra | Supabase + Vercel | Free tier → $45/mo |

### Direction 2: Ship vertical skills into agent directories, ride the distribution layer

- **What to build:** Pick a vertical you know (reconciliation, SEO audits, compliance checks), package it as a Claude Code skill or subagent, publish to subagents.cc and codegen.com for zero-cost acquisition, monetize via a Pro tier or companion SaaS.
- **Stack:** Claude Code writes the skill (a SKILL.md plus scripts, 1–3 days). Distribution is free. Payments via Gumroad or Lemon Squeezy. Lowest-CAC entry point — but defensibility only comes from proprietary data and relentless updates.

### Direction 3: Price-drop arbitrage — rebuild verticals that didn’t pencil out six months ago

- **What to build:** With Opus-class capability at $5/$25, two categories turn profitable again: reasoning-heavy document processing (legal, insurance, cross-border compliance) and long-context codebase/document Q&A. Products with negative gross margin in January can hit 70%+ now.
- **Stack:** Route by task tier — Sonnet 5 for routine paths, Opus 5 ($5/$25) only for reasoning-critical steps. Model routing is the new cost discipline. Supabase backend, Stripe/Paddle payments.

| Model tier | Price (in/out per M tokens) | Use for |
| --- | --- | --- |
| Sonnet 5 | ~half of Opus | Default workload |
| Opus 5 | $5 / $25 | Reasoning-critical paths |

### Direction 4: The flip model — build fast, sell on Indiemaker

- **What to build:** Use agents to take a validated micro-need to $200–500 MRR in 1–2 weeks, list on Indiemaker at 30–40x monthly revenue, roll proceeds into the next one. Fits builders who are better at spotting demand than running products long-term.
- **Stack:** Claude Code + Vercel + Supabase to ship; Reddit/HN search for validation; 1kprojects.com to exit. One discipline: only build things with real payments attached — no pure traffic plays.

## Risk Factors

- **Thin wrappers get eaten by the next model release.** Any product that’s a thin wrap on model capability can lose its reason to exist in a single release cycle.
- **The skill/directory layer commoditizes fast.** A skill file has no moat; copy-paste skills drown within a quarter. Defensibility = proprietary data + relentless updates.
- **AEO/GEO rules are set unilaterally by the platforms.** A citation tactic that works today can die overnight when an LLM changes its retrieval or ranking. Don’t bet everything on one channel.
- **Auto-growth tactics live on borrowed time.** Reddit/Quora auto-posting can be banned overnight — fine as one channel, fatal as the whole product.
