## Key Insights

The value in AI apps is migrating fast — away from the model and into everything wrapped *around* the model. Jensen Huang calls that layer the **harness**; GitHub’s trending page calls it the wave of `-skill` repos; and Cognition just proved that even an agent’s *personality* is an acquirable asset by buying Poke. Meanwhile Google shipped Gemini Spark, a 24/7 cloud-resident agent, to paying users only.

The division of labor has never been clearer for solo builders: **big tech owns the base models and the generic always-on assistant. You own the skills layer, the vertical workflows, and the compliance plumbing.** Those three layers are too fragmented and too niche for platforms to bother with — and users pay for them anyway.

Numbers that actually matter this cycle:

- **54K stars** — last30days-skill, a one-person research skill for Claude Code / Gemini CLI, up from ~11K in March. A ~4x jump in four months for a Markdown-file-plus-scripts product.
- **$100M at a $1B valuation** — what Prentis (the computer-use agent lab co-founded with Reid Hoffman and Mark Pincus) is reportedly raising. Headcount: 25.
- **$35B** — the Apollo/Blackstone private-credit deal financing Anthropic’s compute. Inference costs keep structurally falling.
- **~800M people** — covered by the new US–EU AISS framework requiring third-party audits for high-risk AI systems before deployment. That’s a compliance-tooling market created overnight.

## Market Trends

### The `-skill` repo explosion: agent skills become their own category

Something unusual is happening on GitHub trending: the top repos aren’t frameworks or models — they’re tiny `-skill` repos. The flagship is **last30days-skill**, a research skill for Claude Code and Gemini CLI that fans out across Reddit, X, YouTube, Hacker News, and Polymarket in parallel, scores and dedupes results, and returns a cited brief in 2–8 minutes. It went from ~11K stars in March to **54K now**, with siblings like taste-skill trending alongside it.

Why it matters:

- It validates Huang’s harness thesis: what makes a model *usable* is the execution scaffolding around it — and most of that scaffolding will be built by third parties, not labs.
- Skills are radically cheap to produce: a SKILL.md file plus a few scripts. That’s a solo-builder-shaped product if there ever was one.
- Distribution is free: Claude Code, Gemini CLI, and every agent runtime are competing to grow their skill ecosystems. The platforms are doing your customer acquisition.

### Generic agents consolidate upward; “always-on” becomes a paid tier

Google began rolling **Gemini Spark** out to US AI Pro subscribers last week. It runs on Google Cloud VMs, is powered by Gemini 3.5, integrates deep into Workspace, and keeps working when your laptop is closed — triaging email and prioritizing your calendar every morning. Free users don’t get it at all.

In parallel, **Cognition acquired Poke**, the SMS-based personal agent known for proactively texting users and following up like a friend. Cognition explicitly said Poke’s interaction style and personality will be folded into Devin — making the AI software engineer feel like a colleague.

Read together:

- Always-on background agents just went from demo to monetized product tier.
- The asset Cognition bought wasn’t infrastructure — it was **proactivity and personality**. Interaction design is becoming a moat component.
- Microsoft’s new Copilot routes tasks across models — GPT-5.6 drafts email in Outlook, Claude-5 crunches data in Excel. **Multi-model routing is now default architecture**, mirrored on the open-source side by the fast-iterating claude-code-router project.

### Compute and capital: inference keeps getting cheaper, GPUs get easier for small teams

Apollo and Blackstone structured a **$35B** private-credit vehicle to fund Anthropic’s compute expansion (buying custom Google TPUs and leasing them back). Together AI closed its Series C and partnered with **Y Combinator to launch a dedicated YC GPU cluster**. Capital markets are turning compute into a bond-like asset class — the long-run effect is cheaper inference for everyone downstream.

On the model front, GPT-6 is rumored for an early **August** release, and leaks suggest Gemini 3.5 Pro has matched GPT-5.5 on coding. Frontier coding models are converging — which means **model choice is no longer a moat**, for you or your competitors.

## Build Directions

The two questions this report exists to answer: *what should I build, and with which stack?* Five concrete answers this cycle.

### 1. Treat agent skills as a product line

**Build:** Pick a domain where you have an information edge — e-commerce sourcing, SEO audits, earnings-call digestion, contract-clause comparison — and package it as a Claude Code / Gemini CLI skill. Open-source the core, charge for the pro version.

| Item | Detail |
| --- | --- |
| Stack | SKILL.md + scripts; GitHub for distribution; Gumroad or Polar.sh for the paid tier |
| Pricing | $19–49 one-time for pro skills is landing well |
| Cost / timeline | Near zero; first version in 1–2 weeks |

The window: there’s no standardized “skill store” yet. Early publishers own the search traffic.

### 2. Vertical always-on agents — before Spark generalizes into your niche

**Build:** Spark is a generic secretary; it won’t touch deep professional workflows. Ship a background agent for one profession: listing monitoring + follow-ups for real-estate agents, invoice chasing for accountants, candidate warm-keeping for recruiters. It runs daily and pushes results proactively.

| Item | Detail |
| --- | --- |
| Stack | Claude API or GPT-5.5 for reasoning; Supabase (DB + cron + auth); Resend/Twilio for outbound; Stripe subscriptions |
| Pricing | $29–99/month |
| Cost / timeline | $50–200/month burn; MVP in 4–6 weeks |

Steal the Poke lesson: the cadence and *human feel* of proactive messages **is** your retention.

### 3. Multi-model routing and cost observability

**Build:** If Microsoft routes tasks across GPT-5.6 and Claude-5, every 5–50 person AI team needs the same thing plus a bill they can read. Build team-level model routing SaaS or an agent cost dashboard.

| Item | Detail |
| --- | --- |
| Stack | Fork/extend claude-code-router or LiteLLM; OpenRouter for unified access; PostHog for events |
| Pricing | Per-seat, B2B |
| Cost / timeline | Open-source base exists; launchable in 6–8 weeks; 2–3 paying teams covers costs |

### 4. AISS compliance micro-SaaS

**Build:** The US–EU AISS framework requires high-risk AI systems to pass independent audits and publish training-data provenance and failure-mode docs before deployment. Small AI companies have no legal team. Sell the shovel: pre-audit checklists, technical-documentation generators, data-provenance registries.

| Item | Detail |
| --- | --- |
| Stack | Next.js + Claude API for doc generation; templated questionnaire → compliance doc bundle |
| Pricing | $199–499 per doc bundle, or subscription |
| Cost / timeline | 6–8 weeks; regulation just landed, audit standards still forming — peak shovel-selling window |

### 5. Personality-as-a-component for agent builders

**Build:** Poke’s acquisition proved proactive, personable interaction design has standalone value. Package personality/proactivity components for agent developers — when to interrupt, how to phrase follow-ups, how to escalate — as an npm package, hosted API, or productized consulting.

| Item | Detail |
| --- | --- |
| Stack | Prompt engineering + a state machine for outreach timing; distribute via npm or hosted API; acquire via Indie Hackers / X case studies |
| Cost / timeline | Near zero; portfolio-driven — ideal if you have writing and product taste |

## Risk Factors

- **Platform absorption.** Every Spark capability expansion kills a cohort of horizontal “AI personal assistant” startups. If you’re not vertical and deep, you’re running Google’s A/B test for free.
- **No skill standard.** The `-skill` format is bound to specific runtimes today. A spec change could strand your catalog overnight — stay light and fast to re-port.
- **Model-release steamrolling.** If GPT-6 ships in August as rumored, tools that exist to patch model weaknesses (context stitching, hallucination checking) get absorbed into native capability.
- **Compliance cuts both ways.** AISS creates tooling demand, but if *your* product is classified high-risk, audit costs can kill a solo project. Avoid medical diagnosis and credit-decision territory.

- ✅ Adopt multi-model routing per task type — teams typically shave 30–50% off inference spend.
- ✅ Selling B2B into the US/EU? Fold AISS documentation into your sales collateral now and turn compliance into a closing argument.
