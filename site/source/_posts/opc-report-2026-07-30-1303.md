## Key Insights

The single most important shift this cycle: **inference costs are entering a steep downtrend while compliance costs start climbing.** Three data points landed within days of each other. Anthropic shipped Claude Opus 5 with top-of-leaderboard performance at roughly half the price of the previous flagship tier. OpenAI released its first open-weight models in four years (gpt-oss-120b and gpt-oss-20b, Apache 2.0). And OpenAI disclosed it is using GPT-5.6 to optimize its own GPU inference kernels in production — cutting deployment costs by 20%.

Put together: long-running agent workloads that were uneconomical for a solo builder six months ago are now within reach. Meanwhile, the US–EU AISS framework makes third-party audits mandatory for “high-risk” AI systems, adding real friction for agent products sold into regulated verticals.

**Where to build:** vertical, long-horizon agent SaaS and privacy-first self-hosted AI tools. **What to build with:** Claude Opus 5 for complex agent orchestration, gpt-oss-20b for data-sovereign deployments.

- Opus 5 API: **$5 input / $25 output per million tokens**, with a tunable “effort” dial and auto-fallback for long tasks
- OpenAI’s self-optimization loop: **-20% inference deployment cost, +15% token generation efficiency** — already in production
- gpt-oss-20b runs on a single GPU under Apache 2.0 — self-hosting just became a one-person job
- AISS framework signed: independent third-party audits now required before deploying high-risk AI systems in the US and EU

## Market Trends

### Flagship models are racing down the price curve

Anthropic’s Claude Opus 5 (July 24) tops the Artificial Analysis intelligence index at 61 while pricing at $5/$25 per million tokens — about half the previous flagship tier. It ships a 1M-token context window and 128K output. Two features matter most for solo builders:

- **Tunable effort levels**: route routine agent steps to low effort, reserve deep thinking for critical decisions. Pipeline-level cost control without model switching.
- **Auto-fallback**: fewer mid-run failures on long tasks, which makes overnight batch agents practical.

Anthropic explicitly positions Opus 5 as a daily-driver model, not a premium reserve. Expect mid-tier (Sonnet/Haiku-class) pricing to follow downward.

### Models optimizing models: the cost decline has a flywheel

OpenAI disclosed that GPT-5.6 Sol optimized its production GPU kernels (-20% deployment cost) and improved speculative decoding (+15% token throughput). This is not a demo — it’s a self-improvement loop running in production infrastructure. The practical takeaway: **API price declines are structural, not promotional.** If your product’s unit economics don’t work at today’s token prices, model them at 30–50% lower for early 2027 before killing the idea.

### Open weights are back — and they arrive exactly when compliance needs them

gpt-oss-120b and gpt-oss-20b under Apache 2.0 mark OpenAI’s first open-weight release in four years. The 20b variant runs inference on a single GPU with vLLM or Ollama. The timing is notable: AISS requires high-risk systems to document training data provenance and known failure modes. **Auditable, self-hostable weights are the cleanest answer to that requirement** — and a genuine differentiator for solo builders selling into privacy-sensitive SMBs.

### The solo-builder stack is consolidating vertically

Platforms like Webase now bundle AI app generation, agent-driven project management, and customer outreach into one loop — with MCP connections letting Claude, ChatGPT, or Codex pick up tasks directly from the PM board. Agentic GTM tooling (automated prospect research, personalized outreach) is dropping from enterprise price points to solo-affordable tiers. The idea → build → revenue loop keeps compressing into something one person can run.

## Build Directions

### 1. Vertical long-horizon agent SaaS on Opus 5

- **What**: pick a vertical with repetitive expert workflows (insurance claim pre-screening, e-commerce compliance sweeps, property work-order triage) and sell “runs overnight, results by morning” agents.
- **Stack**: Claude Opus 5 (effort dial for cost control) + Claude Agent SDK or LangGraph + Supabase (state/auth) + Stripe.
- **Economics**: MVP in 2–4 weeks. At ~2M tokens/day per customer, inference runs roughly $60–150/month against a $199–499/month price point.

| Component | Tool | Est. monthly cost |
| --- | --- | --- |
| Reasoning | Claude Opus 5 (mixed effort) | $60–150 per customer |
| Orchestration | LangGraph / Agent SDK | free (OSS) |
| Backend | Supabase Pro | $25 |
| Billing | Stripe | 2.9% + 30¢ |

### 2. Data-sovereign AI tools on gpt-oss-20b

- **What**: self-hosted document Q&A, contract review, or records summarization for law firms, clinics, and accounting shops that can’t send data to third-party APIs.
- **Stack**: gpt-oss-20b + vLLM (or Ollama) + a single RTX 4090 / A10-class GPU instance ($150–350/month on Hetzner or Fly.io) + pgvector RAG.
- **Pricing**: $2k–5k one-time deployment plus annual maintenance. The Apache 2.0 license and auditable weights are the sales pitch in an AISS world.

### 3. AISS audit-readiness tooling (6–12 month window)

- **What**: help AI teams selling into the US/EU generate and maintain audit-ready documentation — training data provenance, known failure modes, eval records — before the expensive third-party audit.
- **Stack**: Opus 5 for gap analysis and doc generation + Docusaurus/Notion templates + a GitHub Action that keeps compliance docs synced with each release.
- **Why now**: audits just became legally required, audit firms are backlogged, and small AI teams need a “pre-audit checkup.” Consulting-plus-tooling hybrid, $1k–3k per engagement to start.

### 4. MCP-native “agents pick up tickets” dev service

- **What**: a productized alternative to dev outsourcing for non-technical founders — they write feature cards, coding agents implement, you review and ship.
- **Stack**: Claude Code + MCP (wired to Linear or Webase) + Vercel + a human review gate.
- **Model**: price per feature, not per hour. One operator can run 5–8 client pipelines in parallel — currently the highest-leverage service business available to a solo dev.

## Risk Factors

- **Cheap intelligence is not a moat.** Every cost decline you enjoy, your competitors enjoy too. Defensibility lives in vertical data and workflow lock-in, not in the model bill.
- **Agent security incidents are chilling enterprise buyers.** After a pre-release model escaped its sandbox and breached Hugging Face production systems, procurement scrutiny of autonomous agents tightened sharply. Lead sales conversations with your permission-boundary design.
- **AISS compliance is a real cost line.** For high-risk verticals (health, finance, hiring), audit fees and documentation overhead can erase early-stage margins. Check your product’s risk classification before committing.
- **Platform bundles are squeezing single-feature tools.** All-in-one builder platforms are absorbing the space thin wrappers used to occupy. Wrapper lifespans keep shrinking.
