# An npm Worm Hit 868 Packages in a Day. Verification Is Now the Job.

**August 4, 2026 — Build Directions for Independent Operators**

At some point this morning, someone got into the GitHub account of the maintainer behind `keyv` — a key-value caching library pulling roughly 127 million weekly npm downloads. They pushed two files directly to `main`, cut a release, and let the machinery do the rest.

By 13:37 CEST, **868 packages across 1,381 versions were compromised, representing over 2 billion monthly installs.**

The detail that should ruin your afternoon is not the scale. It is that the poisoned releases were published to npm **with valid provenance, signed by GitHub Actions**. The attestation chain worked exactly as designed. It just attested that malware had been built by the correct pipeline from the correct repository.

The same week, Epoch AI and METR published a benchmark showing frontier models reimplementing entire programs — including a 16,000-line bioinformatics toolkit — from observed behavior alone, with no access to source.

These two stories are the same story.

---

## Key Insights

Generation got cheap. Attestation got automated. Neither of those is verification, and the gap between them is where this week’s damage happened.

**What actually changed:**

- **Signed provenance is not a safety property.** It proves *where* code came from, not *what it does*. A compromised maintainer account produces perfectly-signed malware. Anyone whose security model was “check for provenance” had no security model.
- **`preinstall` is still the whole attack surface.** The dropper ran on `npm install`, before anything else. `--ignore-scripts` remains the single highest-leverage line of defense, and almost nobody sets it.
- **Code is no longer a moat, and now there is a benchmark for it.** MirrorCode’s strongest model scored **56%** reimplementing whole programs from behavior. If your product’s defensibility is the source, it has a shelf life.
- **The frontier is expensive but the direction is clear.** One large MirrorCode task cost **$2,600 and ran 19 days unattended**. That is not your budget. It is a preview of next year’s price.
- **Comprehension is being tracked as a liability.** “Prevent cognitive debt by manually retyping LLM-generated code” took 502 points and 413 comments — right behind “LLMs reward expertise” at 1,036 points. The community is converging on the same bottleneck from two directions.

## Market Trends

### The Trust Layer Broke in the Place Everyone Assumed Was Fixed

Here is the mechanism, because the mechanism is the lesson. Every package in the `keyv` family received two files — `setup.mjs` and `Math_Symbol.js` — plus a `"preinstall": "node setup.mjs"` entry in `package.json`. Run `npm install` and `setup.mjs` executes before your install finishes. It silently downloads the Bun runtime from a legitimate GitHub release URL and uses it to run the real payload: a 728 KB obfuscated file that harvests npm auth tokens from `.npmrc`, GitHub CLI tokens including classic PATs and OIDC tokens, AWS access keys from `~/.aws/credentials`, and HashiCorp Vault tokens from `VAULT_TOKEN`.

Then it propagates. It infects packages belonging to *other* maintainers who installed a compromised package. That is why nine packages became 868 in hours. The exfiltration target is a public GitHub repository whose description reads “Shai-Hulud: Here We Go Again” — the attackers named it after the previous round.

The blast radius is instructive precisely because these are boring dependencies: `keyv` at 619M monthly downloads, `flat-cache` at 565M, `file-entry-cache` at 557M, `cacheable-request` at 133M. Nobody chose these. They arrived four levels deep under a linter. And the spread reached packages at Deliveroo, Picsart, and Qlik.

For a solo operator the arithmetic is unforgiving. A compromised AWS key on a team of fifty means an incident channel and a rotation runbook. On a team of one, it means your production database, your Stripe webhooks, your customers’ data, and your npm publishing rights all belong to someone else while you are asleep. There is no second person to notice.

The uncomfortable follow-on: **AI coding agents install packages unattended.** An agent resolving a build failure by adding a dependency at 3am is running `preinstall` scripts with your credentials in the environment, with nobody reading the output. The autonomy we spent this year building is also an unsupervised install-execution channel.

### Behavior Is a Specification, and That Cuts Both Ways

MirrorCode gives agents a program’s observable behavior and asks them to rebuild it with no source access. Solutions must match the original’s output exactly on end-to-end tests, including held-out tests. Twenty-five targets across Unix utilities, serialization tools, bioinformatics, interpreters, static analysis, cryptography, and compression.

The strongest model scored 56%. It reimplemented `gotree`, a 16,000-line bioinformatics toolkit the authors estimate would take a human engineer weeks. The largest single attempt cost $2,600 and ran for 19 days without human intervention.

Two conclusions that point in opposite directions, and you need both.

The defensive one: if your product’s behavior is fully observable and your value is the implementation, you are describing a spec that a competitor can hand to an agent. Not today at your price point — $2,600 per attempt with a 56% success rate is not a business. But the trajectory is unambiguous, and “we wrote a lot of careful code” is depreciating as a moat.

The offensive one is more useful. The paper’s own framing is that agents succeed **“especially when requirements are precisely specified.”** That is the actual finding. The scarce input is not code generation — it is a specification precise enough to be checkable, and a test suite that catches the difference between working and plausible. That is the thing you can sell.

### Comprehension Debt Is Being Priced In

Ankur Sethi’s post describes a workflow that sounds absurd and is quietly correct. He instructs his coding assistant never to edit files — only to propose changes in chat, which he then **types in by hand**.

His accounting is honest: instead of 10x faster, he is maybe 2x. What he buys is a spatial map of his own codebase. He knows where everything lives, catches hallucinations because typing forces him to slow down, and refactors as he goes. His closing line — *“there will come a time when we no longer understand how large parts of our digital infrastructure are put together”* — landed the week a worm walked through 2 billion monthly installs.

Put next to Sean Goedecke’s argument that identical models produce wildly different outcomes depending on whether the operator can distinguish good output from plausible output, the picture resolves. **Generation is commoditized. Evaluation is not.** For a solo founder this is not philosophy, it is an on-call rota of one. When a customer hits an edge case on a Saturday, you are the only person who can debug it, and code you have never read is code you cannot debug.

### Inference Is Falling Off the Cloud

Three data points in 36 hours. `Swiftlet` — an 80B Qwen running in **4.3 GB of RAM on a Mac**, and a 35B on an iPhone — took 237 stars on its first day. Someone posted DeepSeek V4 Flash running on a single AMD MI300X. And Cloudflare published its serving stack: quantizing the KV cache from BF16 to FP8 doubled Kimi K2.6’s in-memory context from roughly **686,000 tokens to about 1.37 million with no accuracy change.**

The engineering is different in each case but the economic consequence is identical: **capable inference is escaping per-token pricing.** For anyone building alone, that changes product shape, not just cost. If the model runs on the user’s device, your marginal cost per user is zero, your data-handling compliance story becomes “nothing leaves the machine,” and one-time pricing becomes viable again in a market that had fully converted to subscriptions.
