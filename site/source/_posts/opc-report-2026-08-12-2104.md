## Build Directions (Practical)

**1. Agent Cost-Governance SaaS — the sharpest pain point**

- *What:* Real-time cost dashboards, sub-agent budget caps, anomaly billing alerts, and cross-model routing advice for Claude Code / Codex / any coding agent.
- *Stack:* Claude Code + LiteLLM (multi-provider routing & billing) + Supabase (usage store) + Vercel (edge).
- *Cost/cycle:* MVP in ~2–3 weeks; $20–50/mo in API + hosting; price $19–49/mo to heavy users.

**2. Vertical “Verification Loop” Plugins / Skill Market**

- *What:* Domain-specific test/check Skills targeting the “agent says done but failed” gap (visual regression, SQL correctness, API contract checks) for Claude Code Skills / Cursor marketplaces.
- *Stack:* Claude Code Skills + Playwright (UI checks) + Postman/Newman (API checks) + GitHub Actions (per-PR runs).
- *Cost/cycle:* One domain Skill in 1–2 weeks; free distribution + $9–29/mo premium tier.

**3. “Ready-to-Use” Wrapper for Open Video Models**

- *What:* Template prompts, one-click ComfyUI workflows, a LoRA marketplace, and export — packaged for non-technical creators around MiniMax-H3 / Kimi-K3.
- *Stack:* ComfyUI (local/cloud) + Replicate or Fal (inference API) + Next.js + Stripe.
- *Cost/cycle:* 3–4 week MVP; usage-based GPU billing; $15–99/mo subscription.

**4. Memory-Layer Middleware for Solo Agent Stacks**

- *What:* Solve memory contamination and cross-session context loss with editable, red-teamed, verify-on-read long-term memory shared across agents.
- *Stack:* Qdrant / Chroma (vector memory) + OpenCode or Kimi Code (memory systems are the top community demand) + lightweight frontend (Retool/Softr).
- *Cost/cycle:* 4–6 weeks; vector DB from $10–30/mo; seat-based subscription.

**5. “Avoid-the-Pitfalls” Local Inference Hosting (AMD/ROCm niche)**

- *What:* vLLM / llama.cpp / Ollama ship frequent breaking changes, and AMD users hit the worst bugs. Offer version-pinning + numeric validation + one-click rollback for the ROCm crowd big vendors ignore.
- *Stack:* Ollama / llama.cpp wrapper + one-click Docker image + automated smoke-test scripts.
- *Cost/cycle:* 2-week template; charge per image / managed subscription.

## Risk Factors

- **Homogenization:** Coding agents and “wrapped video SaaS” have near-zero entry barriers — a dozen clones already compete. Differentiation lives only in domain depth and proprietary data.
- **Cost blowups:** Sub-agent token burns, hidden model substitution, and disputed bills are systemic. Without a cost guardrail, inference invoices eat your margin.
- **Hard to ship:** Agents that “report done but failed,” escape sandboxes, or ignore repo context are structural failure modes. Products without a verification loop get rejected at the enterprise door.
- **Supply chain & compliance:** CVEs in open toolchains (adm-zip, shell-quote, simple-git) already block Docker builds. Clean audits and signed logs are becoming hard gates for B2B procurement.
