## 📈 Market Trends

### 1. AI coding enters the “write-the-whole-thing” phase — the harness is the new battleground

Claude Code’s own framing puts the model as just the kernel; the real engineering lives in the *harness* around it — how it boots, manages state, schedules tools, handles permissions, connects MCP, spins sub-agents, and compresses context. The lesson for solo founders: stop hunting for the cleverest prompt. Learn to author **Rules, Hooks, and sub-agent topologies**.

OpenCode’s surge to ~100k stars confirms the demand. It’s 100% open source, model-agnostic, ships LSP support, parallel sessions, and a client/server split (remote-control the agent on your laptop from your phone). The community is voting with forks: **control and cost matter more than raw model quality** for a one-person operation.

“Harness Engineering” — designing the environment and intent rather than writing the code — has moved from an OpenAI-posed idea (Feb 2026) into shipped team practice. For a solo founder, your harness *is* your product moat.

### 2. Agent orchestration is splitting: from “build an agent” to “manage agents”

MCP shipped its **largest-ever update on 2026-07-28** — going stateless and formally adding MCP Apps (interactive surfaces) and Tasks (long-running jobs). The practical effect: agents calling external tools stops being a per-platform format war.

Product Hunt data agrees. Across recent AI launches, developer tools and agent infrastructure consistently dominate; a majority of top products now ship open source. The obsession has flipped from “make the agent chat” to “make the agent *do*.” Vercel-adjacent edge / serverless deployment remains the default substrate.

We’re also seeing “separation of powers” orchestration — e.g. Sol Advisor splits delivery into an architect (requirements), an executor (code), and a read-only reviewer (byte-level verification). Role isolation is how you keep an autonomous agent from quietly shipping garbage.

### 3. Agents are getting their own wallets: agentic commerce is booting up

The Visa + Artemis report is the reality check: x402’s cumulative volume is **>90% wash trading and tests — real market is only ~$15M**. But the rails are real: Google (AP2), Mastercard (Agent Pay), and Corpay (Agent Card — issue virtual cards to authorized agents within preset spend controls) are all in.

“Your next customer is an agent” is quietly becoming true in retail: AI shopping assistants are a new traffic front door, and brands are already sweating how to make their product data get *preferentially scraped and recommended* by agents.

> ⚠️ Early-stage caution: agent payments are equal parts bubble and opportunity. Build the plumbing (protocols, controls, reconciliation) before you build “the first agent storefront.” Most C-side agent shopping today is nine parts wash.

## 💡 Build Directions (the actionable part)

Every direction below answers **what to build** and **which AI tool stack** — with scenario, rough cost, and timeline.

### Direction 1 — Vertical agent orchestration templates (sell the *harness*, not the code)

- **What:** Package a Claude Code / OpenCode config — Rules + Hooks + sub-agent topology — for one narrow workflow (indie-store SEO content pipeline, contract first-pass review, e-com support KB). Ship as a subscribeable template library.
- **Stack:** Claude Code (quality-critical, ~$100–200/mo) *or* OpenCode + cheaper model (Gemini/DeepSeek, $10–30/mo) · MCP to data sources · GitHub to host · Stripe for subs.
- **Cost / timeline:** 1–2 weeks for the first vertical template; near-zero marginal cost. Price $19–49/mo per template.

### Direction 2 — “Upstream services for agents” (BYOK tools / API gateway)

- **What:** YC’s blunt take — the new SaaS should be *built for agents*. Ship an agent-friendly API (structured output, clean schema, machine-callable) and let other agents be your first customers.
- **Stack:** Supabase (DB + auth, free tier) / Neon (serverless Postgres) · expose via MCP · Vercel edge · **write docs for machines**, not humans.
- **Cost / timeline:** 2–4 weeks MVP; infra $0–50/mo (free tier + usage).

### Direction 3 — The “bookkeeper” layer for agentic commerce

- **What:** A virtual-card + budget-control + reconciliation middleware for SMBs that want agents to buy/procure on their behalf (rides the Corpay Agent Card / x402 idea). SaaS sub + tiny take-rate.
- **Stack:** Node/Python backend · Stripe Treasury-class or open-banking API · rules engine for spend caps · front end spun up fast with Cursor/OpenCode.
- **Cost / timeline:** 4–8 weeks (compliance is the main wall). Best fit for solo founders with fintech/compliance background.

### Direction 4 — Managed + value-add on open-source alternatives

- **What:** OpenCode is hot but大多数人 can’t set it up or govern it. Sell a hosted OpenCode + shared rules marketplace + usage dashboard. Turn open-source complexity into recurring revenue.
- **Stack:** OpenCode (OSS) · Docker hosting · object storage for sessions · usage analytics · Stripe.
- **Cost / timeline:** 2–3 weeks; linear marginal cost, low ACV — needs volume. $9–29/mo.

### Direction 5 — Agent ops-for-hire to non-technical super-individuals

- **What:** Many people have domain know-how but can’t configure agents. Build them an industry-specific agent pipeline (real-estate listing summarizer, consultant research agent) and charge monthly ops.
- **Stack:** n8n (fair-code, self-hostable workflow automation) · OpenCode · vertical data APIs · monthly retainer.
- **Cost / timeline:** 1–2 weeks per client; $200–1000/mo per client. Pure leverage on your time.

## ⚠️ Risk Factors

- **Fast homogenization:** Agent templates and rules are trivially copied once public. Your moat is industry data + real war stories, not the code.
- **Demo ≠ delivery:** “The agent runs a demo” is not “the agent ships reliably.” Permissions, long context, and runaway sub-agents are the deep end of the pool.
- **Compliance & money risk:** Anything touching agent payments / bookkeeping hits licensing and audit weight that can sink a small team.
- **Runaway compute/API cost:** A heavy agent can quietly push your bill past $200/mo. If pricing doesn’t cover inference, you lose money at scale.
- **Bubble signal:** Agentic commerce real volume is only ~$15M with ~90% wash — don’t get carried by the “next frontier” narrative.
