## 📈 Market Trends

### 1. AI Coding Enters the Self-Writing Phase — and the Stack Has Stratified

The tool chain has quietly settled into a consensus shape across Indie Hackers and r/SaaS:

- **Bolt.new / Lovable** — scaffold an MVP in seconds, validate fast, then graduate to a real IDE.
- **Cursor Pro ($20/mo)** — daily interactive coding; its tab-completion and visual diffs are unmatched for iteration speed.
- **Claude Code ($20+ / mo, or API)** — terminal-native agent for large refactors, architecture, and autonomous multi-file work. Independent testing shows it uses **~5.5x fewer tokens** than Cursor on the same complex task while finishing faster with fewer errors — but Cursor’s in-editor flow wins for rapid daily edits. They’re complementary, not competing.

Pricing anchors are now clear: Cursor Pro $20/mo; Claude Code API rates are **$5/$25 (Opus 4.8) and $2/$10 (Sonnet 5) per million tokens in/out**. One rule dominates your budget: **output tokens always cost 5x input**, so long Opus sessions add up fast.

> **What it means:** “Vibe coding” is ending in “agentic engineering” — not because the model got smarter, but because it got *disciplined*. Give agents an org structure (gstack’s 23 roles: CEO-decides, designer-reviews, eng-manager, QA, release-manager) and they collaborate, cross-review, and ship like a real team. The skill to build in 2026 is *directing that team*.

## 🛠️ Build Directions (Practical)

**Direction 1 — Vertical “Agent Skill Pack” store**

- *What:* Productize the gstack idea — for one vertical (Shopify merchants, legal SaaS, local-service booking) ship a library of specialized agent roles + workflow templates, so non-terminal solo founders can direct an agent team.

**Direction 2 — Lightweight “Agent Cost & Security” panel for solo founders**

- *What:* The Aug 1 batch proved demand (DepthData, VulX Watch). Build a personal unified panel: track real Claude Code / API spend, flag common vulnerabilities in AI-generated code, suggest savings. Not enterprise-heavy — a version *one person can read*.
- *Stack:* Vercel (host) + Supabase (usage data) + your own Claude Code (build) + Anthropic usage API.

**Direction 5 — “De-slop” quality layer for AI output**

## ⚠️ Risk Factors

- **Homogenization:** Everyone uses the same Cursor + Claude + Supabase stack, so products look alike. The only moat is domain depth and proprietary data — not the tools.
- **Agent autonomy risk:** Claude Code / multi-agent loops will write code you have to *undo*. Tan himself calls it “a junior engineer you trust to write code but always review.” Set approval boundaries; don’t grant full terminal freedom.
- **Creeping cost:** Free tiers feel safe, but heavy agent use quickly hits $100–$200/mo; API output tokens are 5x input, and long Opus sessions burn. Watch `/cost` — don’t wait for a scary bill.
- **Platform/model dependency:** Products built directly on a foundation model’s chat UI have the thinnest moat (a model upgrade can vaporize the category); infrastructure layers with telephony/data/compliance (voice) are more durable. Know where your switching cost lives before you build.
