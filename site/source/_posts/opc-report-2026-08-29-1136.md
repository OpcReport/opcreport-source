# The One-Person Company Stack Is Taking Shape—Here’s What to Build With It

*OPC solo-founder AI trend report · Aug 29, 2026 · for indie hackers and solopreneurs*

## Key Insights

The “one-person company” is no longer a metaphor. It is a stack of APIs you wire together: write code (Claude Code / Cursor), run the business (Naïve), get paid (x402), and talk to customers (Phonely / Fish Audio). The moat has moved from “can you code” to “can you pick one vertical workflow and find a distribution wedge.”

**Decision-relevant numbers:**

- Claude Code Pro is bundled at **$20/mo**; the realistic solo daily-driver is **Max 5x at $100/mo**.
- Naïve’s **$28.5M Series A** (30,000+ dev customers, 10x revenue in 6 months) proves demand for “let agents incorporate and operate companies.”
- x402 drops per-call settlement to **~$0.001** vs a **~$0.10** card floor, making pay-per-agent-call viable for the first time.

## Market Trends

### 1. AI coding has crossed into “write-its-own-code” territory

Cognition (Devin) is reportedly raising at ~$40B on a **$492M ARR run-rate**, enterprise usage **+50% MoM for 6 months** — but it is pitched as doing long-tail grunt work (legacy refactors, platform migrations), not replacing engineers. Signal: coding agents are a real line item for enterprises.

Pricing has settled. Claude Code’s default model is Opus 5 since July 24; Pro is $20/mo bundled. Open-source `opencode` (MIT, 193k stars), `Cline`, and `Kilo Code` run BYOK at $0 tool cost. Real cost-in-use: ~$13/dev active day, $150–250/dev/mo enterprise.

- Proof: Steven Goh shipped **NinjaPear** in 2 weeks with Claude Code, **$15K MRR** at 6 months, solo.
- Proof: Tony Dinh’s **TypingMind**: 5 days to v1, **$22K** in one-time sales on day 11, BYO API key, no backend.

### 2. The agent infrastructure layer is being built at scale

YC W26 was the largest batch ever (180+, 80%+ AI-native, ~35% agent-native); the fastest-growing sub-category is agent infrastructure — marketplaces, monitoring, security, evaluation. S26 started June 23, Demo Day Sept 10.

W26 companies are building the “operating system for agents”: Tensol (agents get email/phone/tool access), Moda (“Sentry for autonomous systems”), Compresr (context compression to cut cost), Naïve (one API call incorporates a company, sets up payments, email, cloud, accounting).

- Naïve: **$28.5M Series A** (Nexus, YC), 30,000+ dev customers, 10x revenue in 6 months. Two hard stops remain human: KYC/KYB and payments.

### 3. Voice agents moved from IVR replacement to autonomous sales and service

Phonely closed **$16M Series A**: AI voice agents answer calls, book appointments, close — 99.7% accuracy, sub-400ms, millions of calls/mo; one client replaced **350 human agents in a month**; $10M+ insurance sold for a single customer; setup under 5 minutes.

Fish Audio **$52M seed**: voice models, $21M ARR, 8M+ users, started as a single-GPU open-source side project. Underlying models are commoditizing fast; the opening is vertical workflow + platform APIs.

## Build Directions

### Direction 1 · Vertical voice agent (answer calls / book / pre-qualify leads)

- **What:** pick one local-service niche (dentist booking, home-service follow-up, B2B lead triage) and ship an agent that listens, answers, and closes.
- **Stack:** Phonely or Vapi + LiveKit (telephony) + ElevenLabs / Cartesia / Fish Audio (voice) + OpenAI Agents SDK or Vercel Eve (orchestration) + Stripe (billing).
- **Cost / period:** ~$20–50/mo platform + usage; usable build in 1–2 weeks. Phonely live in under 5 minutes.

### Direction 2 · An “agent-ready” pay-per-call API / MCP tool (x402 monetization)

- **What:** wrap one capability you already have (search, inference, format conversion, a data source) as an endpoint other agents pay for in USDC per call.
- **Stack:** Cloudflare Workers + x402 facilitator (Coinbase / Cloudflare) + Node SDK; native MCP+x402 (charge per tool call).
- **Cost / period:** near-zero infra; days to ship one paid action (per-result search / per-inference / per-conversion). Test unhappy paths (duplicate request, paid-not-delivered, retry).

### Direction 3 · Vertical micro-SaaS built by a coding agent

- **What:** pick a named workflow (GTM, invoicing/tax, enrichment) and ship a subscription micro-tool.
- **Stack:** Claude Code (Pro $20 or Max 5x $100 for heavy use) + Supabase (free → $25/mo) + Vercel (free → $20/mo) + Stripe / Lemon Squeezy (billing) + OpenAI / Anthropic API.
- **Cost / period:** MVP in days–2 weeks (NinjaPear 2 weeks, TypingMind 5 days). Sell the outcome, not the feature.

### Direction 4 · An autonomous back office for your own one-person company

- **What:** hand incorporation, payments, email, phone, accounting to agent orchestration; you keep decisions and KYC.
- **Stack:** Naïve API (one call from Claude Code / Codex / Cursor sets up company, payments, email, cloud, QuickBooks) + Linear Loops (recurring agent workflows) + Claude Code (build/maintain).
- **Cost / period:** usage-based; automate the repetitive back office first, keep a human-approval threshold.

### Direction 5 · Production-grade agent with durability, evals, observability

- **What:** an agent that needs reliability (support triage, document processing) — checkpointing, human-in-the-loop, evals.
- **Stack:** Vercel Eve (agent = a directory of files, compiles to Vercel Functions; 6 built-in prod capabilities: durable execution, sandboxed compute, human-in-the-loop, subagents, evals, OpenTelemetry) or Dapr Agents / Microsoft Agent Framework (production-grade, 30+ DBs, SPIFFE identity).
- **Cost / period:** shippable in a weekend. Vercel runs 6 agents internally; its support agent resolves 92% of tickets autonomously.

## Risk Factors

- Coding agents’ hallucination rate spikes on complex/legacy codebases; “autonomous” demos overstate reliability — keep a human review loop and don’t omit its cost.
- Agent-payment rails (x402 / AP2) are young and still moving; isolate behind an adapter, never thread into core billing.
- Voice-agent space is consolidating around a few platforms; training your own model is a losing bet — layer on APIs.
- “Agent-native” is crowded (YC ~35% agent-native); differentiation comes from vertical depth + distribution, not the agent itself.
- Compliance hard stops: KYC/KYB and payments still require a human; autonomous-company infra has regulatory gates.

## Action Recommendations

**New solo founders:**

- ✅ Pick ONE named workflow; ship an MVP in ≤2 weeks with Claude Code + Supabase + Vercel.
- ✅ Sell the outcome, price real ROI (Indie Hackers: B2B productivity averages $1,089 MRR).
- ✅ Lock distribution to one vertical community (Indie Hackers / a Reddit sub / Product Hunt) — not a broad launch.
- ✅ If you do voice, stack Phonely / Vapi APIs; skip model training.

**Established small teams:**

- ✅ Add an x402-gated endpoint to your existing API to capture other agents’ traffic.
- ✅ Move production agents to Eve / Dapr / MAF so durability, evals, observability are defaults.
- ✅ Watch the agent-payment identity layer (Cloudflare pay); set hard spend caps + human-approval threshold + audit log.

## What it means

The stack for a one-person company is now composable from off-the-shelf parts. The winners this cycle won’t be the teams with the best agent — they’ll be the ones who pick a painful vertical workflow, ship it in weeks on a coding agent, and distribute it through a community the incumbents ignore. The infrastructure (code, run, pay, talk) is ready; the bottleneck is taste and distribution.
