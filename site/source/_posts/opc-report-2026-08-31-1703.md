## 🛠️ Build Directions (practical)

**Two questions, answered up front:**

1. **Which direction?** Skip generic chat wrappers. Build one of: a *metric-bearing execution agent*, a *solo-founder orchestration layer*, an *agent control plane*, a *vertical vibe-coded SaaS*, or an *edge micro-SaaS*.
2. **Which tools?** Each direction below names the stack, the use case, and rough cost / timeline.

### Direction 1 — Metric-bearing execution agent (not a chat shell)

- **Build:** Pick a repetitive enterprise workflow with hard metrics (hours, resolution rate, capacity). Make it SMS / voice / API-native. Anchor on Sidekick (factory dispatch), HappyRobot (logistics voice).
- **Stack:** **Claude Code** (backend + integrations) + **Speko / OpenRouter** (route by language & cost) + **Twilio** or lightweight telephony + vector store for SOPs. Cost: API metered, MVP ~$500–2K; timeline 2–4 weeks.

### Direction 2 — Agent orchestration OS for solo founders (meta play)

- **Build:** A coordination layer where AI CEO / CTO / CMO orbit one company goal with a daily review, and money / positioning decisions route back to human approval. Anchor on Soloop, gstack.
- **Stack:** OpenClaw-style harness + **GBrain-style markdown memory** (export your own notes/email) + **skill files** (write weekly tasks as reusable markdown) + scheduled jobs. Cost: near-zero on own infra + API; timeline 1–2 weeks to a usable version.

### Direction 3 — The agent control plane (cost / security / observability)

- **Build:** Cost attribution per step + permission boundaries + MCP session replay + failure detection for long-tail agent builders. Sapiom ($35M) and Obsidian ($85M) already proved willingness to pay.
- **Stack:** Self-built Runtime on the **MCP protocol** + custom eval / Sentry hookup; price as PaaS $20–200/mo. Cost: mostly engineering time; timeline 4–8 weeks.

### Direction 4 — Vertical vibe-coded SaaS (Lovable + Supabase + a niche)

- **Build:** Pick a narrow industry you actually understand. Lovable for UI, Supabase for data + auth, Claude Code for hard logic. **Moat is domain data + distribution, not code.**
- **Stack:** **Lovable** ($25/mo) or **Replit** ($25/mo) + **Supabase** ($25/mo entry, vectors + functions) + **Claude Code** ($20/mo) + **Stripe**. Build cost dropped from ~$200K to ~$5K; timeline: MVP in a weekend, chargeable in 2–4 weeks.

### Direction 5 — On-device / edge micro-SaaS

- **Build:** Put the agent inside an existing OS (iOS App Intents / Core ML) or a small hardware box where only the result syncs to the cloud. Anchor on Touchy, Dream.
- **Stack:** Swift + Core ML + Claude or local model (Ollama); or Raspberry Pi + camera. Cost: hardware <$100; timeline 4–8 weeks.

## ⚠️ Risk Factors

- **Red ocean / commoditization:** 20+ well-funded vibe-coding platforms now compete head-on; pure wrappers get caught fast. Moat lives only in data, distribution, and domain depth.
- **Deployment debt:** AI-generated code shows **1.7x** more major issues and **2.74x** higher security-vulnerability rates vs human-written (CodeRabbit, 470 PRs). Force review in production — a Replit agent once deleted a live production database.
- **Compliance tightening:** The EU AI Act entered enforcement in August; Apple’s App Store pulled several vibe-coding apps under Guideline 2.5.2, stretching review from 1–2 days to 7–30+. Budget compliance and review time before launch.
- **Runaway compute cost:** Autonomous agents bill every step; Sapiom’s $35M exists precisely because “no one can say what the agent spent” is a real hole. Set cost caps and permission boundaries before going live.
