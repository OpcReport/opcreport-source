## Build Directions (actionable)

**1. Vertical, approval-first Agent OS**  
Build a workflow desk with a human approval gate for law, healthcare, construction, or regulated verticals. The agent runs the process; a human clicks “approve” at the critical step. Avoid the generic-chatbot red ocean.

- *Stack:* Claude Code / Codex CLI (backend) + Supabase (data/auth) + custom MCP server (industry systems) + Vercel (one-click publish).
- *Cost/cycle:* MVP in 2–4 weeks, $0–$500 to start. Reference: Soloop hit #10 on PH’s August leaderboard.

**2. “AI coworker” micro-SaaS**  
Don’t build a Q&A bot; build something that delivers an outcome — like Viktor.com living in Slack, or Clara AI SDR turning site visitors into qualified pipeline. You’re selling “it finished the job,” not “it can chat.”

- *Stack:* Cursor 3 (parallel multi-agent edits) + Claude Code (big refactors) + OpenAI Codex (benchmark tasks) + Slack/Teams bot framework.
- *Cost/cycle:* $200–$800/mo (API + hosting), live in 4–6 weeks. Validated by the ex-Google engineer at $5K MRR in 60 days.

**3. Agent-economy middleware**  
Connect agents to the real world (payments, browsing, data). This is the shortest board in the one-person stack and the highest-margin layer.

- *Stack:* Cloudflare Workers + Kitesurf / x402 (agent payments) + your own tool API (model on Treg’s 2,600+ tool aggregation: pay-per-use, zero markup, self-hostable).
- *Cost/cycle:* start on Cloudflare free tier, usage-based; MVP in 2–3 weeks.

**4. “Self-verifying” code-delivery service / templates**  
Help small teams turn “agent output” into “trusted output.” Most agent projects die because the code *looks* right but is broken.

- *Stack:* Claude Code hooks (PreModelSwitch / PostModelSwitch to gate model switches) + CI (GitHub Actions / Depot) + Checksum AI (auto-generates and maintains tests for AI-written code).
- *Angle:* sell non-technical founders “I verify the code your agents write.” Reference: Gewerkton’s solo founder shipped 21 packages in one night with a Codex+Claude fleet, gated by negative controls and mutation tests.

## Risk Factors

- **Commoditization:** the “Agent OS / AI coworker” story is already saturated — a dozen of the 30 PH August entries are agent shells. No differentiation, no traction.
- **Verification gap:** agent output “looks correct” ≠ “is correct.” Skip the verification layer and you ship bugs.
- **Platform dependency:** Cursor/Claude/Codex are merging via acquisition and models retire fast (six Copilot models dropped Aug 31). Locking to one harness risks breakage.
- **Compute / API cost:** model prices are falling, but long-running agent sessions (hours) can still burn tokens unpredictably — set a spend limit.
