## Market Trends

### The agent backbone is now its own fundable category

For most of 2025, “agent” meant a wrapper around a model. In early September 2026 the infrastructure under the agent got priced. Clay (sales agents) doubled to $7.1B on a $115M round (Sept 9). The takeaway for a solo builder: the unsexy middle — guardrails, audit, memory, monitoring — is where the defensible, sellable work is.

### Context engineering became the real moat

“Prompt engineering is out, context engineering is in” stopped being a slogan and became the operating reality. Gartner named context engineering a top strategic tech trend for 2026; analysts expect 40% of enterprise apps to carry task-specific agents by year-end. The failure mode is now well named: **context rot** — context built at pilot time degrades as the business data changes, so an agent that looked perfect in the demo returns plausible-but-wrong answers in production. The practitioner proof is the Vercel AI team’s “bitter lesson”: they removed tools from a complex agent and accuracy went 80%→100%, tokens dropped 40%, speed rose 3.5×. Fewer, better-curated inputs beat more integrations. For a one-person company this is good news: it means leverage comes from *designing the information environment* (memory, retrieval, tool scoping, approvals) — work a solo founder can do — not from training or buying a bigger model. Memory infra matured to support it: Zep, Letta, Mem0 give you a persistence layer; MCP (97M+ installs, now under the Linux Foundation’s Agentic AI Foundation) is the standard connector.

### Browser/computer-use agents are in production — with a reliability asterisk

Browser agents went from research to deployed work in procurement, compliance monitoring and customer onboarding; teams report 60–80% time reductions on supplier-data reconciliation. The infra matured too: Browserbase and Steel run headless browsers at scale, Stagehand gives SDKs, and Browser Use (open-source, 40K+ stars) lets you build your own on any model. But the gap is real: the labs ship faster than they publish benchmarks, complex multi-step workflows still fail, and **prompt injection from web content is unsolved** — a malicious page can redirect your agent. The solo play is narrow, well-scoped back-office tasks with a human approval gate on anything irreversible.

### 1. A vertical “agent backbone” micro-SaaS

- **What:** A narrow trust/control layer for agents in one regulated-ish vertical (finance ops, health-admin, legal review): permission scoping, audit logs, approval gates, skill vetting. You’re selling “this agent won’t do something dumb or unlogged.”
- **Stack:** `Claude Agent SDK` or `Microsoft Agent Framework 1.0` (native MCP + A2A) + a policy/approval layer you build + `LiteLLM` (multi-model routing + prompt caching that can cut input-token cost ~90%) + `Braintrust` / `LangSmith` for observability.
- **Cost / cycle:** Usable build in 2–4 weeks. Proof the layer is fundable: AIR ($50M), Empirik ($21M). Sell to SMBs that already run agents but have no guardrails.

### 2. Context-engineering as a packaged service (per client)

- **What:** Stand up a *stateful context layer* for one workflow per client — e.g., a real-estate broker’s deal memory, a clinic’s patient-context layer, an agency’s client history. The Vercel lesson is your pitch: fewer tools, better-curated context.
- **Stack:** a memory layer (`Zep` / `Letta` / `Mem0`) + retrieval over the client’s docs + `MCP` to wire the few tools that matter + `Supabase` (DB/auth) + `Stripe` (setup + retainer).
- **Cost / cycle:** 1–3 weeks per client. Price as $500–2,500 setup + $300–1,500/mo retainer. Moat = the proprietary data loop you build, not the model.

### 3. Ship faster on the now-controlled coding agents

### 4. A scoped browser/computer-use agent for one back-office task

- **Stack:** `Browser Use` (open-source) or `Anthropic Computer Use` / `OpenAI ChatGPT agent` + `Browserbase` / `Steel` (headless infra, session + CAPTCHA handling) + a human approval gate on payments/credential steps.

## Risk Factors

- **Context rot quietly breaks production.** Context built at pilot time degrades as data changes; an agent can look perfect in demo and return confident wrong answers live. Design for live, stateful context — not a static snapshot.
- **Thin wrappers stay worthless.** Acquisition evidence (35 agentic M&A deals in 12 months, up from 9) shows buyers pay premiums only for distribution + proprietary data; pure API-wrappers get near-zero. Defensibility must come from workflow/data, not the model.
- **Browser/computer-use reliability gap is real.** Labs ship faster than they measure; complex workflows still fail and prompt injection from web content is unsolved. Gate every high-stakes step behind a human.
- **Inference/tool-cost volatility.** API prices fell ~60% in two years but can swing back; a usage-priced product with thin margins is exposed to provider hikes and MCP-governance shifts (still settling under the Linux Foundation).
- **Platform lock-in.** Claude Agent SDK is Claude-only; Microsoft Agent Framework leans Azure. Orchestration choices now create long-term dependencies — wire tools via open MCP to keep an exit.

## Action Recommendations

**Early-stage / solo founder**

- ✅ Pick **one vertical** with a measurable trust or context pain (finance ops, health-admin, a specific back-office chore); don’t build a generic agent.
- ✅ Make **context engineering** your core skill: curate memory + retrieval + tool scoping before adding any new integration. Remember Vercel — fewer tools, better context.

- ✅ Pursue **vertical depth + outcome pricing**; watch the acqui-hire market — buyers pay for distribution + data, near-zero for wrappers.
