## Market Trends

### 1. The token price war just rewrote the solo builder’s unit economics

In a 72-hour window (Sep 1–3), three frontier labs repriced. Anthropic launched **Fable 5.1** with cache reads slashed 75% ($1.00 → $0.25/M) — 25–45% savings on context-heavy agentic workloads — and made **Sonnet 5’s $2/$10 permanent** (cancelling a planned hike). Google shipped **Gemini 3.8 Flash** at a promo $0.75/$3.75 through 2026-12-31, then doubling Jan 1. OpenAI’s **GPT-6 Astra** landed at $10/$50, gated behind a trusted-access program. The Silicon Data token index hit **$0.97/M on Sep 1** — the first time it dipped below $1.

- **Signal:** Base token rates are squeezed about as far as they go. The savings now live in *how much context you reuse* and *which model you route each task to*.
- **Case:** A tool-heavy coding agent running 10k calls/day drops from ~$12,900/mo to ~$8,400/mo on Fable 5.1 cache savings alone — the exact number moves with cache-hit rate.
- **What it means for a one-person company:** stop optimizing for “the cheapest model.” Optimize for cache hits + a router that sends each prompt to the cheapest model that can do it. And treat promo pricing as temporary — Gemini’s rate resets in 2026.

### 2. Browser / computer-use agents crossed from demo to “ships work”

Every major lab now ships a browser-capable agent. OpenAI retired standalone Operator and folded agentic browsing into **ChatGPT Agent / Agent Mode** (its computer-use agent scored 87% on WebVoyager). Anthropic built **Computer Use** into Claude. Perplexity’s **Comet** is a free-ish agentic browser. Open-source **Browser Use** hit 85k+ stars, 87.4% on the Odysseys benchmark, and raised a **$17M seed**. Cost per browser task fell roughly 10x — from $0.50–1.50 (2024) to $0.05–0.15 (2026) self-hosted.

- **Signal:** The web became a programmable surface. A founder can now tell an agent “check these 12 competitor SKUs every Monday at 8am and drop the result in a sheet” — no API, no code.
- **Case:** Small businesses are already handing off competitor price checks, lead research, recurring form filing, and review monitoring to browser agents — the work is repetitive, high-volume, and API-less.
- **What it means:** the solo wedge is not “build a better chatbot.” It’s “do the repetitive clicking for an SMB that has no API.” That is a services + micro-SaaS opportunity with near-zero marginal cost.

### 3. MCP became the default glue — and exposed a security debt

Model Context Protocol crossed **97M monthly SDK downloads** (Mar 2026), grew to **10,000+ active servers**, and was adopted by OpenAI, Google, Microsoft and AWS under Linux Foundation governance — the “USB-C for AI agents.” It collapsed the N×M integration problem into one server per tool. But the speed created debt: **43% of tested MCP servers showed command-injection vulnerabilities**, with 30+ CVEs filed in early 2026, including a CVSS 9.6 RCE.

- **Signal:** One MCP server you write works across Claude, ChatGPT, Cursor and Gemini — portability is now the moat for tool makers.
- **Case:** A niche SaaS with no official agent integration is a greenfield: build one hardened MCP server and every agent builder can use it.
- **What it means:** building and *vetting* MCP servers is a real, undersupplied opportunity. Security (provenance, least privilege, session-scoped auth) is the differentiator, not feature count.

## Build Directions

Concrete, buildable now. Each lists what to build, the tool stack, and rough cost/cycle.

**1. Browser-agent service for SMBs (price monitor / form filing / lead research)**

- **Build:** an agent that does repetitive, API-less web work for local businesses — competitor SKU checks, recurring tax/permit forms, lead list building, review monitoring with draft replies.
- **Stack:** Browser Use or Stagehand (open-source) · Skyvern (no-code visual) · Google Sheets / Airtable (output) · Twilio (alerts) · your own LLM key.
- **Cost / cycle:** self-hosted ~$20–100/mo for ~1,000 tasks; MVP in 1–2 weeks. You replace $0.50–1.50/task (2024) with $0.05–0.15/task.

**2. Cost-optimized model-routing micro-SaaS**

- **Build:** a proxy that routes each prompt to the cheapest model that can handle it, with a live cost dashboard for the customer. Sell “I cut your AI bill 40%.”
- **Stack:** LiteLLM or OpenRouter (routing) · Sonnet 5 ($2/$10) · Gemini 3.8 Flash promo ($0.75/$3.75) · GLM-5.3 Flash (budget).
- **Cost / cycle:** prototype free; ship in 1–2 weeks. Margin comes from the promo spread + cache design.

**3. A hardened MCP server for an underserved niche tool**

- **Build:** one well-scoped, security-vetted MCP server for a SaaS with no official agent integration; sell to agent builders and enterprises.
- **Stack:** MCP TypeScript / Python SDK · host on Smithery or your own · session-scoped OAuth · least-privilege scopes.
- **Cost / cycle:** 1–2 weeks; $20–200/mo SaaS or one-time license.

**4. GEO / AI-search visibility service for local businesses**

- **Build:** make small businesses show up inside ChatGPT / Perplexity / Claude recommendations; monitor mentions and fix structured data.
- **Stack:** content + schema markup · tracked queries in ChatGPT/Perplexity/Claude · reporting in Notion / Sheets.
- **Cost / cycle:** retainer $200–800/mo per client; first client in 1 week.

**5. Local, privacy-first browser agent (bring-your-own-key)**

- **Build:** a Chrome-extension browser agent that runs locally with the user’s own LLM key — no vendor server in the middle.
- **Stack:** Nanobrowser pattern (planner + executor) · BYO OpenAI / Anthropic / Gemini key.
- **Cost / cycle:** free/OSS core; paid Pro. Days to MVP.

## Risk Factors

- **Promo pricing expires:** Gemini 3.8 Flash doubles on 2027-01-01 and GLM’s discount is ending — bills rebound if you hardcoded one model. Design portable and cache-friendly.
- **Browser agents stall on hostile flows:** CAPTCHAs, bot detection, brittle JavaScript checkouts, and anything needing a human judgment call mid-task still break. Keep a human in the loop on money, tax, and legal actions.
- **MCP security debt is real:** 43% of tested servers showed command-injection flaws. Vet server provenance, enforce least privilege, prefer vendor-backed implementations until registry verification matures.
- **Prompt injection is unsolved:** a malicious web page can hide instructions that hijack your agent. Browser agents reading untrusted pages are an open attack surface — isolate and require human approval, don’t just filter.

## Action Recommendations

**If you’re pre-product:**

- ✅ Pick one API-less, repetitive web workflow you know (local business, procurement, research) — not “a general agent.”
- ✅ Stand up a browser-agent MVP with Browser Use / Stagehand + your own key in ≤2 weeks; price per task, not per seat.
- ✅ Route models through LiteLLM/OpenRouter from day one so a price change never breaks you.

**If you already run agents:**

- ✅ Audit every MCP server you depend on for provenance and least-privilege scopes; drop unvetted ones.
- ✅ Move long-context prompts to cache-friendly design (stable system prompt, tool schemas, history) to capture the 25–45% savings.
- ✅ Add human approval on every high-risk browser action (purchase, message, file) and log it for audit.
