## Risk Factors

- **Commoditization:** 44% of YC’s Spring batch pursued “agent-as-a-service.” Generic agents are already a red ocean; without vertical depth you get crushed.
- **Security reality:** GitSpawn proved that *opening an untrusted repo* can run attacker code on your machine before any approval prompt. Patch every CLI coding agent and globally disable `core.fsmonitor`.
- **Compliance / autonomy risk:** autonomous finance/trading agents (e.g., Nina, the crypto-trading agent on Product Hunt) are drawing regulatory scrutiny. Anything that takes autonomous actions needs audit trails and rollback.
- **Compute / single-provider risk:** the model layer is consolidating toward oligopoly (Anthropic targeting $2T). Betting on one provider risks outage or price hikes — keep multi-model fallbacks.
