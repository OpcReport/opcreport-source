## Build Directions (the practical part)

**1. Vertical AI-native service — sell the outcome, not the software**

- *What:* Pick one document-heavy, labor-expensive niche and package the workflow as a service — restaurant-chain monthly close, insurance-broker assistance, tax/audit, healthcare admin. Copy Owner’s logic but narrower. Sell “books closed by the 5th” or “qualified leads +30% in 90 days,” not a tool.
- *Stack:* Claude Code / Codex for the MVP core + n8n / Make for automation + vertical data sources/APIs + human-in-the-loop for edge cases. The customer surface can be a Slack bot or a portal.
- *Cost/cycle:* price on outcome at $300–$2,000/client/month; 4–8 weeks to first paying customer; 60–80% margin.

**2. Hyper-niche Micro-SaaS — 2-week MVP**

- *What:* Don’t build Salesforce. Build the one tool a specific group pays $20–29/month for and never churns because nothing else solves their exact problem — API monitoring dashboards for indie devs, SEO brief generators for niche bloggers, invoice-follow-up automators for freelancers, Etsy product-description generators, Threads/Bluesky schedulers.
- *Stack:* Next.js (front) + Supabase (back/db) + Stripe (billing) + Claude Code / Cursor (code). Ship ugly but working first; design later.
- *Cost/cycle:* 200 customers × $29 ≈ $5,800/mo ≈ ~$70K/yr with near-zero opex; tools $20–100/mo; idea-to-MVP ~2 weeks.

**3. AI-native agency — cash-flow engine, then productize**

## Risk Factors

- **Commoditization of wrappers.** “We use AI” is no longer differentiation — public-model wrappers decay fast. Vertical workflow + customer relationship is the only durable moat.
- **Quality collapse / hard to land.** Over-automation degrades output; agents hallucinate in financial and legal contexts. Keep a human-in-the-loop.
- **Compliance.** New US state laws (California SB 53, Colorado SB 24-205) add AI data obligations starting 2026; feeding customer data into consumer AI tools carries privacy and compliance risk.
- **Compute cost & vendor lock-in.** Codex binds you to OpenAI; Wonderful markets model-agnostic on purpose — lock-in is a real selection risk. AI billing volatility is best hedged with a “base fee + transparent overage” hybrid pricing model.
