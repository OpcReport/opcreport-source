## Market Trends

### 1. The agent runtime is becoming its own product category — and a solo founder can win it

Herdr (founder Can Celik, YC Fall 2026) is a background server that owns each terminal session so fleets of Claude Code, Codex, and Cursor agents keep running when the client disconnects. It organizes sessions by state (working / blocked / idle / done) and exposes a CLI + local socket API. Four months in: **36K GitHub stars, 780K downloads, 1,000+ plugins**, still Apache 2.0 after the raise. The day before the September 8 announcement it shipped **multi-machine management** — run agents on your laptop, a server, and a Mac mini from one terminal. The read: a single developer can build the “control plane” that sits between terminal multiplexers and full agent workspaces, and institutions will pay for it.

- Adjacent open-source players: **OpenHands 1.17.0** (released Sep 9) ships a **container sandbox by default** and is the safest option for unattended agent runs; **amux** is a free MIT orchestrator that runs 5–20+ Claude Code sessions in parallel.
- Why now: coding sessions have stretched from a few prompts into hours of autonomous work. Engineers supervising several agents need to know which session needs attention — and need the work to survive a disconnected client.

### 2. “Personal AGI” is a stack you assemble, not a model you rent

Garry Tan’s Startup School 2026 thesis — *personal AGI*: founder-owned agents with persistent memory, reusable skill files, and their own infrastructure — is turning into a concrete tool category. Tan’s own stack is **gstack** (~123K GitHub stars) plus **GBrain**, a personal knowledge system of ~220K markdown pages covering 25 years of his context. The wedge for solo founders is the **local-first memory layer**:

- **Cabinet** (393 stars) — markdown-as-single-source-of-truth “AI startup OS,” git-versioned memory, 20 pre-built agent templates, BYOAI.
- **Khoj** (~35K stars) — self-hosted second brain, multi-platform, builds agents on your own docs.
- **Local-First Agent KB blueprint** — the boring-but-durable pattern: SQLite + FTS5 for machine search, plain markdown for human state, a CLI as the only integration surface. Provenance makes answers traceable instead of magical.

The strategic point Tan hammers: **whoever controls the skill files controls the cognition.** If your agent’s judgment lives in a company repo under IT policy, you can leave with nothing. Own your markdown.

## Build Directions (the practical part)

## Risk Factors

- **Limit shock.** Claude Code’s summer promo ends Sep 14; heavy users face a ~17% effective cut. Don’t size your runway on promo allowances.
- **Boundary must live outside the agent.** July 2026 OpenAI-agent breaches (Hugging Face production, a dormant German wiki) proved sandboxes can’t be trusted inside the agent. Unattended runs need container isolation (OpenHands) or you supply the boundary.
- **Skill-file ownership.** If your agents’ memory lives in a client’s or employer’s repo, you can be replaced and leave with nothing. Keep your markdown vault portable and git-versioned.
- **Config portability / lock-in.** Claude Code still doesn’t support the cross-tool AGENTS.md standard (Codex does, with ~5K GitHub reactions). Write portable configs so you can switch agents without rewriting your brain.
